# Reporting a security problem

If you find a security problem in the Khaos Workshop, the Khaos Listening Space, the Guild Register or the Khaos
attribution package, tell us privately first.

- Write to **foundation@khaos.dev** with "Security" in the subject.
- Say what is affected (which product and version, or the commit), what you found, and how to reproduce it.
- Please do not publish the details until we have released a fix, or for 90 days from your report, whichever is
  sooner. We will tell you when the fix is out and credit you if you wish.

We acknowledge every report, tell you what we will do about it, and keep you told until it is closed. Security fixes
are made to the latest release; the release notes say which problems a release fixes.

What is in each Khaos Workshop build is listed in its software bill of materials (`sbom.cdx.json`, beside the code in
the built app).
